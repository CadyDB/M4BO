Build Instructions.

so… you wana build our game huh? yea your welcome to do so as you wish!

so what you will need is, the actuall game project that is available at our github and unity version 6000.2.3f1.

once you have downloaded the required version of unity, you can import the unity project, that can be done in the Unity Hub™ in the right corner next to the blue buton labeled "new project".

once you have klicked the "Add" buton you will be presented with a drop down menu asking you if you want to link a local project or one from the world wide web, both can be done but we are going to Focus on the local one.

klick the "add repository from disk" option from the drop down menu, you will be presented with the file explorer or your system, you have to now select the folder where the project that you have downloaded is located.

that will most likely be your downlaods folder, in the downloads folder will be the zip file containing the project, right klick on the zip file and klick extract in the menu that pop's up. ]

once extracted go back to the unity hub window where you have to located your game, that will be your default download folder location. 

Under windows that will be C:\Users\(YOURUSER)\Downloads

Under Mac Os ~/Downloads/ (~ repreisenting your home folder)

Under Linux /home/USERNAME/Downloads OR ~/Downloads/

Once you have located the project folder select it and wait for Unity Hub to add the project.

If you do not have the required version of unity downloaded it will ask you to download it. please do as trying to open the project in a newer version of unity might break somemthing…

once the project is added and the correct version of unity is downloaded you may open the project! that will take a while depending on your hardware... take a minute or 10! 

ok ok so once in unity we need to fix some things IF they are broken. try starting the game, if you get a input error that means that unity has set the active input handeling system to the new system and that is not really that good since we use the old system... 

with your mouse to the the left top corner of the Unity window and klick the tab "edit" once the drop down menu has appeared at the botton there should be another buton labeled "Project settings", once you klick that a new window should pop open.

In the new window it should open the tab "Player". If not, Find it in the Left hand menu.

Once you have located it or are on the "Player" tab open the "Other Settings" Internal Menu.

In that menu that we have just opened locate the switch "Active Input Handeling".

Click on the drop down menu that is on the right of the "Active Input Handeling" and select from that menu either "Both" or "input manager (old)". both work fine.

Once you have done that exit out of that window and go back to where the "Edit" drop down menu is in the unity scene, next to that is a drop down menu labeled as "File"

In the "File" drop down menu click on Build Profiles, a new window should apear on your screen. 

In the window that just opened you should see could profiles for Windows, MacOS and linux (and more if you selected more).

Please scrol to the desired operating system and follow the build instructions there!

For WINDOWS:

Please make sure that there are 15 Scenes in the "Scene List".

if not please add all the scenes that are in the project.

Scroll down to "Platform Settings" and look for "architecture".

From that selection chose "Intel 32-bit" for best compatibility with X86 operating systems. (with this setting the application will be limited to only 4086 mb of ram).

"ARM 64-bit" for the ARM architecture of course. (with this setting idk how much ram the system allows the game to gobble up)

and "intel 64-bit" is the same as "intel 32-but" but does not function on X86 operating systems. (with this setting the application will not be limited to only 4086 mb of ram)

Once you have selected your desired architecture click the build button.

a explorer window will pop up.

from that explorer window please chose the desired location where you wan't to the game to be saved at once its build.

Once the desired location has been selected click "select folder" in the lower right corner of the screen and wait for the game to build.

Once build you may enjoy the game.

For MACOS:

Please make sure that there are 15 Scenes in the "Scene List".

if not please add all the scenes that are in the project.

Scroll down to "Platform Settings" and look for "architecture".

From that selection chose "Intel 64-bit + Apple sillicon" for best compatibility with all Mac Os operating systems. (with this setting the application will be able to run on Intel and Apple Processors).

"Apple sillicon" for the apple M1+ architecture of course. (with this setting the game will NOT run on Intel Mac's of any kind).

and "intel 64-bit" is the same as "Intel 64-bit + Apple sillicon" but does not function on any apple sillicon mac's. (with this setting the application will by limited to Intel based mac's only).

Once you have selected your desired architecture click the build button.

a finder window will pop up.

from that finder window please chose the desired location where you wan't to the game to be saved at once its build.

Once the desired location has been selected click "Open" in the lower right corner of the window and wait for the game to build.

Once build you may enjoy the game.

Github Instalation Instructions.

Proceed to this webpage

https://github.com/CadyDB/M4BO/releases

whatever build is on top/the latest use that.

click on the "assets" drop down arrow in the latest build box.

from there download the correct version of the game for you operating system.

MAC.zip for Apple MacOS for Intel and ARM Mac's

X86.zip for Microsoft Windows for Intel Based processors

Follow the extraction tutorial for your operating system.

Apple Mac Os Extraction:

on mac, once you have downloaded the correct file. locate it. 

on the right side of your dock there should be the "downloads" icon next to the trashbin. click on that and let it pop up.

once the latest downloaded files have popped up, click on the game and mac os should automaticly extract it.

if not please proceed to the downloads folder. it is located at ~/Downloads/ (~ repreisenting your home folder).

When you are in your download folder please right click on the MAC.zip and select from the drop down menu "open with" and from that select "archive utility".

then your game should extract. 

once the game is correctly extracted you should have a new app called "MAC".

that's your game!

enjoy!

Microsoft Windows Extraction:

on windows, once you hace downloaded the correct file. locate it.

on the task bar click on the windows logo on the left side of your screen and type "downloads".

or go to the directory C:\Users\(YOURUSER)\Downloads if you know how to.

once in the download's folder locate the X86.zip file and right click on it.

in the pop down menu klick the "extract all..." option.

a new window will pop up asking you where you wan't the game to be extracted to, select your desired destination and click "extract" in the lower right corner of the window.

wait for the game to extract, the folder where you have extracted the game to should open in a new window after it has finished.

That's your game!
